# Binance Agent OS Mini Hackathon — Track A Checklist

## Before submission

- [ ] Repository is public and the README is complete.
- [ ] `streamlit run app.py` works from a clean environment.
- [ ] Demo mode works without credentials.
- [ ] Live public market mode works.
- [ ] Agent OS MCP setup instructions are visible.
- [ ] No API keys, cookies, tokens or private account data are committed.
- [ ] A short demo video has been recorded.
- [ ] The video clearly shows the multi-agent reasoning chain.
- [ ] The video clearly shows the human confirmation boundary.
- [ ] The official Binance hackathon submission form/survey is completed.
- [ ] The required social-media follow/repost/submission action is completed according to the current official rules.

## Demo video structure

0–10s: Problem

> AI trading agents can generate actions, but users need to understand risk before authorization.

10–35s: Multi-agent scan

> Market → Risk → Portfolio → Decision.

35–55s: Account context

> Paste/use an Agent OS snapshot and show portfolio-aware reasoning.

55–75s: Safety boundary

> The agent proposes. The human authorizes.

75–90s: Agent OS

> Show the Binance MCP endpoint configured in a compatible client.

## Final quality check

The project should answer three questions immediately:

1. What did the agent analyze?
2. Why did it reach this decision?
3. Who authorized execution?
